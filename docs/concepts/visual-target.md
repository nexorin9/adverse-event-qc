# 视觉目标卡 · 不良事件上报数据质检系统

> 结构化视觉目标卡。本环境不具备图像生成能力，**不生成概念图、不放占位图**；真实运行截图另见 `docs/screenshots/`（由实测采集任务写入）。
> 画面类型：**桌面窗口**（三栏主窗口）——与本轮锁定的交付形态（桌面常驻小工具：托盘 + 主窗口三栏）一致。
> 必须可达的约束：只使用标准库 `tkinter` / `ttk` 的样式、颜色、字体、间距与原生 `Canvas` 能实现的效果；不画 WebGL、动画图表或任何现有依赖做不到的东西。

---

## 状态一 · 起始态（刚启动，尚未跑批）

**画面上有什么**

- 顶栏：左侧产品名「不良事件上报数据质检系统」，右侧三个状态位——「投递目录：未监听」「平台：未连接」「待确认 0」。
- 左栏（240px）：批次列表，空态文案「还没有跑过的批次。把科室表放进 inbox/<科室编码>/<期间>.xlsx，或点右上角『刷新』」+ 一个「开始跑批」按钮。
- 中栏（自适应）：越界行表空态，表头（科室 / 行号 / 规则 / 越界值 / 归因）保留但无数据行。
- 右栏（360px）：归因确认面板空态，说明「选中左侧一行查看归因草稿」。
- 状态栏（底部）：一行运行摘要占位「尚未运行」。

**信息层级**：空态文案是画面主角；顶栏状态位次之；表头不抢眼。

---

## 状态二 · 首个可用瞬间（一批跑完，出现越界行）

**画面上有什么**

- 顶栏状态位变为「投递目录：监听中」「平台：已连接」「待确认 47」。
- 左栏出现按期间分组的批次列表，当前批高亮（左侧 3px 主色竖条），每行末尾一条通过率细条（`Canvas` 画的 4px 高条，绿色段=通过比例、灰色段=未通过）；通过率数字等宽右对齐。
- 中栏出现越界行表：表格优先、行高 32px、斑马纹隔行浅底 `#F5F7FA`、表头 sticky；列为 科室 / 行号 / 规则 / 越界值 / 归因；越界值用等宽字体，`事件类型编码` 一类的越界值用错误色 `#C0392B` 标注。
- 右栏显示选中行的归因草稿：建议编码（主色大字）、置信度、依据（次文字 11px）、四类判定标签（拼写漂移 / 口径变化 / 确属新事件 / 信息缺失，分别用中性 / 警告 / 信息 / 成功色标签）、底部「确认」「驳回」两个按钮（确认为 primary，驳回为默认态）。
- 状态栏：运行摘要「本批 8 科室 · 有效 512 行 · 越界 47 行 · 规则 12 条 · 耗时 3.2s · 套件版本 v2026-01」。

**信息层级**：中栏越界值 > 右栏建议编码 > 左栏通过率 > 辅助说明。

---

## 状态三 · 成形态（多批沉淀、确认推进、写回完成）

**画面上有什么**

- 顶栏右侧出现待写队列红条（数量 > 0 时显示，错误色底、白字，宽度随数字自适应）。
- 左栏多个期间分组累积，每组可折叠；条目增多后出现滚动条与分隔线 `#E3E8EF`。
- 中栏支持按科室、规则过滤；行选中态为主色浅底 + 左侧竖条；行 hover 有过渡（150ms）。
- 右栏确认后的行显示状态徽章（已确认 / 已写回 / 待人工分类），待人工分类额外显示降级原因与「重试」入口。
- 状态栏：最近一次写回回执摘要「已写回 12 条发现单（幂等键可查）· 2 条待写」。

**信息层级**：红条（待写）> 状态徽章 > 越界值 > 通过率。

## 视觉语言

| 项 | 取值 |
|----|------|
| 背景底色 | `#F5F7FA` |
| 面板底色 | `#FFFFFF` |
| 主色 | `#1F5FA9` |
| 成功 | `#2E7D4F` |
| 警告 | `#B26A00` |
| 错误 | `#C0392B` |
| 主文字 | `#1F2933` |
| 次文字 | `#5B6770` |
| 分隔线 | `#E3E8EF` |

- **字体族**：`PingFang SC`（macOS）／`Microsoft YaHei`（Windows）／`Noto Sans CJK SC`（Linux），回退 `sans-serif`。
- **字体层级**：页头 15px / 面板标题 13px / 表格正文 12px / 辅助说明 11px（≥4 级）。
- **数字**：通过率、计数、耗时统一 `tabular-nums`，右对齐；同列小数点对齐。
- **间距栅格**：8px 栅格 —— 8 / 16 / 24 / 32；表格行高 32px。
- **圆角与阴影**：卡片 4px，浮层 6px，模态 8px；阴影只用一层极轻投影。
- **留白密度**：表格优先、信息密度高；不使用消费级大卡片与大留白。

## 必须可达的约束（只画当前依赖真能做出来的）

| 想要的效果 | 可达方式 | 不可达（禁止出现在画面里） |
|------------|----------|--------------------------|
| 通过率细条 | 原生 `Canvas` 画矩形段 | 圆角进度环、渐变填充 |
| 表格 sticky 表头 | `ttk.Treeview` + 独立表头容器随滚动同步 | 真正的层叠滚动阴影 |
| 斑马纹与选中态 | `ttk.Treeview` `tag_configure` 配色 | 自绘表格单元格 |
| 状态徽章 | `ttk.Label` + 底色样式（tone 名义色） | 彩色渐变胶囊 |
| 加载态 | 进度条 `ttk.Progressbar`（不确定态动画） | 骨架屏逐块淡入 |
| 空态插图 | 内联矢量小图标（细描边几何图形） | 插画风格插图、3D 图标 |
| 悬停过渡 | `ttk` 样式状态 + 150ms 颜色过渡 | 弹簧动画、手势交互 |
